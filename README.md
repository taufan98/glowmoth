Glowmoth is a night-garden arcade game. You are Pip, a glow-moth: catch golden pollen (combos up to x5), grab blue moonpetals to freeze the hunting ash-wisps, collect green leafhearts for +1 life, and dodge red cinders and grey ash-wisps. 3 lives; 750 points earns the Night's Crown, then endless mode. Controls: arrows/WASD or mouse/touch drag, P pause, M mute, Enter/Space start/restart.

## Run it

```sh
python3 -m http.server --directory game
```

Then open http://localhost:8000 in a desktop browser. No build step, no network needed.
