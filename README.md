# Glowmoth

A night-garden arcade game. You are Pip, a glow-moth: catch golden pollen (combos up to x5), grab blue moonpetals to freeze the hunting ash-wisps, collect green leafhearts for +1 life, and dodge red cinders and grey ash-wisps. 3 lives; 750 points earns the Night's Crown, then endless mode.

Controls: arrows/WASD or mouse/touch drag, P pause, M mute, Enter/Space start/restart.

Open `game/index.html` in a browser and play. No build step, no network needed.

Built for the make.fun best-game-01 bounty.
